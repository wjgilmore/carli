# carli 0.2.0

carli 0.2.0 adds multi-stage Unix pipelines with the same terminal-safety and
job-control behavior as standalone commands.

## Highlights

- Connect any number of commands with the ordinary `|` operator.
- Use quoting or escaping to pass a literal pipe character.
- Read the final pipeline stage's status through `$?`.
- Apply input and output redirection independently to each stage.
- Run pipeline built-ins in isolated child processes so state changes do not
  leak into the parent shell.
- Control a whole pipeline as one job with Ctrl-C, Ctrl-Z, `jobs`, `fg`, and
  `bg`.
- Clean up every pipeline stage when an interactive shell receives `SIGHUP`.

See the [pipeline guide](https://github.com/wjgilmore/carli/blob/v0.2.0/docs/pipelines.md)
for syntax, status and redirection rules, examples, and current limitations.

## Installation

With Rust 1.88 or newer:

```sh
cargo install carli-shell --version 0.2.0
```

The installed executable is named `carli`.

Before registering carli as a login shell, read the
[installation safety guide](https://github.com/wjgilmore/carli/blob/v0.2.0/docs/installation.md).
Do not use the Cargo-managed executable directly as a login shell. Build a
release checkout and use its guarded installer to place the executable at a
stable system path.

## Compatibility warning

carli is not compatible with Bash, Zsh, or POSIX shell scripts. Command
separators, conditionals, command substitution, functions, loops, globbing,
background launch with `&`, `|&`, and `pipefail` remain unsupported. Test the
programs and login paths you depend on before changing an important account's
shell.
