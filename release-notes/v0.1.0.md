# carli 0.1.0

This is the first public release of `carli`, a small Unix shell focused on
predictable interactive behavior and cautious login-shell installation.

## Highlights

- Interactive editing, persistent history, and configurable prompts.
- Environment and previous-status expansion, quoting, and redirection.
- Foreground process groups, signal handling, terminal restoration, and basic
  job control.
- Non-interactive command and batch modes with startup configuration.
- Transactional installer and guarded uninstaller for Linux and macOS.

## Installation

With Rust 1.88 or newer:

```sh
cargo install carli-shell --version 0.1.0
```

The crates.io package is named `carli-shell`; the installed executable is
named `carli`.

Before registering `carli` as a login shell, read the
[installation safety guide](https://github.com/wjgilmore/carli/blob/v0.1.0/docs/installation.md).
Do not use the Cargo-managed executable directly as a login shell. Build a
release checkout and use its guarded installer to place the executable at a
stable system path.

## Compatibility warning

`carli` is not compatible with Bash, Zsh, or POSIX shell scripts. It does not
yet implement pipelines, command separators, conditionals, command
substitution, functions, loops, or globbing. Test the programs and login paths
you depend on before changing an important account's shell.
